# 📊 Sales Performance Dashboard (Power BI)

## 📌 Project Overview

This project analyzes sales data using Power BI. It includes data cleaning, KPI creation, and interactive visualizations.

## 🛠 Tools Used

* Power BI
* Power Query
* DAX

## 📈 Features

* Monthly Sales Trend
* Profit by Region
* Top 10 Products
* Interactive Slicers

## 🔍 Key Insights

* Sales peak towards year end
* West region generates highest profit
* Top products contribute major revenue
